# 文件操作模块

## 维护触发器

- 后端资源操作路由、版本字段或错误码发生变化时同步更新 API 封装和错误映射。
- 新增重命名、移动、回收或恢复入口时，必须复用 `useFileOperation`，不要在组件中直接调用 `fetch`。
- 对话框的提交状态、焦点回收和冲突输入行为变化时同步更新本目录测试。

## 模块概述

本模块负责文件工作区的重命名、移动、移入回收站、恢复和永久删除操作。API 层只负责请求，`useFileOperation` 负责 mutation、Query 失效和版本冲突刷新，UI 对话框只负责展示和交互。

## 文件结构

```text
file-operations/
├── api/file-operation-api.ts       # 资源操作和回收站 API
├── components/
│   ├── rename-dialog.tsx            # 重命名表单
│   ├── move-picker-dialog.tsx       # 目标目录选择与环检测
│   └── delete-confirm-dialog.tsx    # 软删除/永久删除确认
└── hooks/use-file-operation.ts      # 统一 mutation 与错误恢复
```

## 核心架构

- 请求体始终携带资源当前 `version`，后端返回 409 时刷新资源详情并保留原对话框。
- 成功操作失效资源详情、目录列表和回收站查询；移动同时失效源目录与目标目录。
- 操作权限只由后端返回的 `capabilities` 驱动，UI 不复制角色判断。
- 永久删除采用两步确认，防止误操作。

## 已实现功能

- 重命名、移动、移入回收站、恢复、永久删除。
- 名称冲突、版本冲突、共享结构根权限错误的稳定中文提示。
- 移动目标自节点/后代节点禁选。
- mutation loading 防重复提交和对话框焦点回收。

## 缺失功能

- P1：多选批量操作。
- P1：移动选择器的异步全量目录树和搜索。
- P2：撤销操作和操作历史。
