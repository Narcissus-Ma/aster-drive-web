# 匿名公开访问维护说明

## 维护触发器

当公开链接路由、匿名响应、签名 URL TTL、文档节点白名单或只读预览策略变化时，需要同步更新本 feature、共享 API 和安全测试。

## 组件概述

`PublicSharePage` 位于认证保护布局之外，通过 token 获取后端公开响应，只渲染只读文档、图片/PDF 预览和下载链接。错误信息统一为无效/失效，避免泄露资源历史存在性。

## 核心架构

- `use-public-share.ts` 使用独立 Query key，并以 `auth: false` 请求公开接口。
- 文档内容采用受限节点递归渲染，不挂载 Tiptap 编辑器，也不提供编辑或上传操作。
- 文件预览直接使用后端返回的短时签名 URL，下载入口沿用服务端 disposition 和 filename。

## 已实现功能

- `/public/share/:token` 主路由和 `/share/:token` 兼容路由。
- 文档只读渲染、图片/PDF 预览、下载和无效链接错误态。

## 缺失功能

- 富文本 marks、表格和媒体节点的完整只读渲染。
- 匿名访问埋点、限流提示和更完整的文本文件内嵌预览。
