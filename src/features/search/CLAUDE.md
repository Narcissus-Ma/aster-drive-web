# 全局搜索模块

## 维护触发器

- 搜索参数、筛选字段、分页协议或取消语义变化时，同步更新 API、Hook 和 URL 测试。
- 搜索结果打开行为、键盘交互或工作台布局变化时，同步更新结果列表、搜索入口和本文件。

## 模块概述

`search` 提供应用壳层中的全局资源搜索入口。搜索词和筛选条件保存在 URL，查询使用 TanStack Query，输入变化经过 300ms 防抖，并把请求取消信号传递给 API 客户端。

## 文件结构

```text
search/
├── components/
│   ├── global-search.tsx               # URL 驱动的搜索表单与结果浮层
│   ├── global-search.module.css       # 搜索表单和浮层样式
│   ├── search-result-list.tsx         # 结果列表、空态、错误态和分页入口
│   └── search-result-list.module.css  # 结果列表样式
└── hooks/use-resource-search.ts       # 防抖、分页、取消和资源去重
```

## 核心架构

- URL 使用 `q`、`kind`、`updated_from`、`updated_to` 保存搜索状态，刷新和前进/后退可恢复表单。
- `useResourceSearch` 只在防抖后的非空词条上请求，并按资源 ID 合并分页；查询切换期间隐藏旧结果。
- 结果列表通过 `onOpen` 交给组合层，组合层负责记录最近访问和选择目标工作区路由。

## 已实现功能

- 全局搜索输入和资源类型/更新时间筛选。
- 300ms 防抖、游标分页、错误/空态和结果键盘可操作按钮。
- 搜索结果打开时记录最近访问并回到资源父目录。

## 缺失功能

- P1：搜索历史和高级语法。
- P1：搜索结果高亮、排序和批量操作。
- P2：服务端全文索引和离线搜索缓存。
