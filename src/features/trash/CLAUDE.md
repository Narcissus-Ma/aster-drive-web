# 回收站模块

## 维护触发器

- 回收站 API 分页、状态或恢复冲突语义变化时同步更新查询、页面和测试。
- 恢复或永久删除入口变化时，继续复用 `useFileOperation`，保持版本校验一致。
- 新增回收站展示字段时同步更新本文件的结构说明。

## 模块概述

回收站页面展示当前用户可恢复的顶层已删除资源，并提供恢复和永久删除入口。恢复发生名称冲突时保留页面和冲突对话框，允许用户处理原目录后重试。

## 文件结构

```text
trash/
├── components/
│   ├── trash-page.tsx                # 回收站列表与操作编排
│   └── restore-conflict-dialog.tsx   # 恢复名称冲突提示
└── hooks/use-trash-resources.ts      # 分页查询与资源合并
```

## 核心架构

- `useTrashResources` 使用 TanStack Query 无限查询并按资源 ID 去重。
- 恢复、永久删除共用文件操作 mutation，成功后自动失效回收站缓存。
- 回收站按钮始终以资源 ID 作为可访问名称，提交中禁用，避免重复请求。

## 已实现功能

- 回收站分页列表、空状态、错误重试和加载更多。
- 传递资源当前版本的恢复与永久删除。
- 恢复名称冲突对话框和永久删除二次确认。

## 缺失功能

- P1：按删除时间、类型筛选。
- P1：批量恢复/永久删除。
- P2：回收站保留期限和自动清理倒计时。
